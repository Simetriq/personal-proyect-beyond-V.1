1. VISIÓN GENERAL Y OBJETIVO DEL PROYECTO
--------------------------------------------------------------------------------
El proyecto consiste en el desarrollo de un Asistente de Combate y Mesa Virtual (VTT)
altamente automatizado, diseñado específicamente para el sistema de juego de rol
"Anima: Beyond Fantasy".

Anima es reconocido por su profundidad táctica y su densidad matemática (cálculos de 
porcentaje de daño, tipos de armadura/absorción TA, tiradas enfrentadas, acumulaciones
de Zeon y Ki, modificadores de estado, pifias, críticos con localización, etc.).

El objetivo principal de este VTT es asumir toda esa carga matemática densa en tiempo
real a través de un servidor backend, permitiendo que jugadores y Director de Juego (GM)
disfruten de partidas fluidas, rápidas, visualmente deslumbrantes (estética cyberpunk/mística
oscura) y con una narrativa de combate brutal.


2. ARQUITECTURA Y STACK TECNOLÓGICO
--------------------------------------------------------------------------------
* FRONTEND:
  - Framework: React + TypeScript + Vite.
  - Estado Global: Zustand (stores modulares para combate, sockets y personajes).
  - Comunicación: Socket.io-client para sincronización en tiempo real.
  - Diseño / UI: CSS Vanilla / TailwindCSS con paleta oscura, acentos neón (cian, púrpura,
    rojo carmesí, dorado místico), fuentes tipográficas Cinzel/Roboto y animaciones reactivas.
  - Componentes Clave: PlayerView, GameMasterDashboard, TurnOrderTracker, BattleLogPanel,
    CombatTargetPanel, MagicConsole, DefenseReactionModal.

* BACKEND:
  - Entorno: Node.js + TypeScript + Express.
  - Real-Time Engine: Socket.io (Arquitectura Orientada a Eventos con Máquina de Estados).
  - Persistencia: Prisma ORM (con base de datos relacional PostgreSQL / SQLite).
  - Motor de Reglas (Engine): Módulos puros en TypeScript para resolución de combate,
    dados, hemorragias, agonía/muerte, artes marciales y magia.
